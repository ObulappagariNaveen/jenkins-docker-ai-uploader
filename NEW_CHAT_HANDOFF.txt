Website URL:

http://localhost:8081

Main files:
- app.py
- Dockerfile
- docker-compose.local-ollama.yml
- Modelfile.jenkins-failure-explainer
- README.md

How to start:

cd /Users/obulappagari.naveen/Documents/Codex/2026-05-10/files-mentioned-by-the-user-jenkins/jenkins-docker-ai-uploader
ollama list
docker compose -f docker-compose.local-ollama.yml up -d --no-build

If the Docker image is missing:

docker compose -f docker-compose.local-ollama.yml up -d --build

If the Ollama model is missing:

ollama pull llama3.2:3b
ollama create jenkins-failure-explainer -f Modelfile.jenkins-failure-explainer

How to use:
1. Download Jenkins build consoleText as .txt.
2. Open http://localhost:8081.
3. Upload the Jenkins log.
4. Read the generated plain-English explanation.

- /data/output
